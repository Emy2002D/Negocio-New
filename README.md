# Negocio-New

**Autor:** Emiliano Vega Diaz  
**Proyecto:** Panel de administración y pedidos con Python + MongoDB

## 🧠 Descripción

Negocio-New es una aplicación web desarrollada con **Flask** y conectada a **MongoDB Atlas**, diseñada para gestionar productos, usuarios y pedidos de forma eficiente. Incluye paneles diferenciados para administrador y cliente, con funcionalidades como:

- Agregar, editar y eliminar productos
- Visualizar pedidos en tiempo real
- Marcar pedidos como "listos"
- Panel público de productos disponibles
- Carrito de compras dinámico con confirmación

Este proyecto es parte de mi aprendizaje para dominar el backend con Python y bases de datos NoSQL.

## ⚙️ Tecnologías utilizadas

- Python 3
- Flask
- MongoDB Atlas
- HTML, CSS (épico estilo Galicia)
- JavaScript (fetch, modales, dinámico)
